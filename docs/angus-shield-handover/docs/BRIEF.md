# Angus Shield — product brief (DRAFT, for Kris to correct)

**Status:** draft, 25 September 2026. Scope decided (the whole job); the items under "Still open" are not.

## One line

The financial system for trade businesses: invoice, get paid, pay bills, and lodge on time.

## Who it is for

Trade businesses that today run Xero or MYOB beside a job system. Many of them will also run
SiteVIP.

## The test

**Is it simple if it's missing a function? No.** A financial system that can't do one of the owner's
money jobs sends them to a second system for it, and two systems is never simpler than one. So
version one does the whole job. It is simple because of how each function works, not because
functions were left out.

## Version one: the whole job

1. Chart of accounts and general ledger (append-only, double-entry)
2. Customers, quotes and invoices
3. Suppliers and bills
4. Bank feeds and reconciliation
5. **Payroll with Single Touch Payroll**, including super
6. **GST and BAS, lodged directly with the ATO**
7. Reports: P&L, balance sheet, cash flow, aged receivables and payables
8. Moving over from Xero or MYOB: opening balances, contacts, open invoices and payroll year-to-date

## Start now: these take the longest

- **Becoming an ATO Digital Service Provider.** Direct lodgement and STP both need it: the security
  questionnaire and the Operational Framework. This is a queue we don't control, so start it
  before the code.
- **Bank feed access.** Either Consumer Data Right accreditation or a CDR intermediary, or a
  bank-feed provider. We need to pick one and apply.

## Regions

Each region either ships complete (its own tax, payroll and lodgement) or doesn't ship at all. A
region that is half done fails the same test. **Proposed:** Australia first and complete, then each
region complete in its turn.
